What MyCount Collects

Current collection fields and their storage. IP hashing and browser fingerprint generation are not implemented.

Required means a stored value is present for every newly accepted page view. Historical records may lack newer fields.

The browser UUID is scoped to the browser profile, origin, and site label. It persists across IP changes; clearing storage or switching devices can create a new ID. Views without persistent storage remain unidentified.

Location values are copied into visits; GeoIP refreshes do not change historical locations. The reserved region code and fingerprint columns remain empty.

Privacy preference flags are recorded as metadata; the current script does not use them to disable collection.

See the collection documentation for more details.
