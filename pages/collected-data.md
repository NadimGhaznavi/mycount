This page describes the current implementation. MyCount records page views
and associates them with a random browser ID when local storage is available.
IP hashing and browser fingerprint generation are not implemented.

## Page-view data

“Required” means a stored value is present for every newly accepted page view.
Optional values may be absent because the browser does not supply them or a
lookup cannot determine them. Historical records may lack newer fields.

| Value | Source | Stored in | Required | Details |
| --- | --- | --- | --- | --- |
| Site label | Script's `data-site` setting | `pages.site` | Yes | Identifies the tracked site. |
| Page URL | Browser location, validated by collector | `pages.url` | Yes | Origin and path only; query string and fragment are excluded. |
| Receipt time | Collector clock | `page_views.received_at` | Yes | UTC time when the collector processes the event. |
| Browser ID | Random UUIDv4 generated by our script | `page_views.visitor_id` | No | Reused from local storage for the same origin and site label. |
| IP address | Request connection or trusted local proxy | Not retained in visit storage | N/A | Used for the GeoIP lookup; no IP hash is stored. |
| Country code | GeoIP lookup | `page_views.country_code` | No | Copied from the matching IP range. |
| Region name | GeoIP lookup | `page_views.region_name` | No | Source dataset's `state` value. |
| City name | GeoIP lookup | `page_views.city_name` | No | May be absent even when country or region is known. |
| Preferred languages | `navigator.languages` | `page_view_languages` | No | Stored in preference order; the required payload list may be empty. |
| Referring host | `document.referrer` | `page_views.referrer_host` | No | Client sends only the referring origin; collector retains only the normalized hostname. |
| User-agent string | `navigator.userAgent` | `page_views.user_agent` | No | Payload field is required, but an empty string is stored as `NULL`. |
| Browser family and version | Parsed user-agent | `page_views.browser_family`, `browser_version` | No | Unknown values are `NULL`. |
| OS family and version | Parsed user-agent | `page_views.os_family`, `os_version` | No | Unknown values are `NULL`. |
| Device category | Parsed user-agent | `page_views.device_category` | Yes | `desktop`, `mobile`, `tablet`, or `other`. |
| Device brand and model | Parsed user-agent | `page_views.device_brand`, `device_model` | No | Present when identified by the parser. |
| Bot classification | Parsed user-agent | `page_views.is_bot` | No | Parser result; not proof that a visitor is human. Empty user-agent leaves it unknown. |
| Browser details | Browser APIs | `page_views.client_details` | No | Optional JSON fields listed below. |

The collector validates `schema_version`, `event`, and the request's `Origin`
header, but does not store them as separate visit fields. The database generates
page/view IDs and a page URL hash for indexing. `page_views.page_id` references
`pages`; language rows reference their page view. Location values are copied
into each visit, with no foreign key to GeoIP ranges, so GeoIP refreshes do not
change historical locations.

The schema also has `region_code`, `fingerprint`, and `fingerprint_version`
columns, but the current collector leaves them `NULL`.

## Optional browser details

Each field below is stored inside `page_views.client_details` when supplied.
None is required. Unsupported or `null` values are omitted; an empty details
object is stored as `NULL`.

| Field | Meaning / browser source |
| --- | --- |
| `screen_width`, `screen_height` | Screen dimensions from `screen.width` / `height`. |
| `available_width`, `available_height` | Available screen area from `screen.availWidth` / `availHeight`. |
| `color_depth`, `pixel_depth` | Screen color and pixel depth. |
| `viewport_width`, `viewport_height` | Window's inner width and height. |
| `pixel_ratio` | `devicePixelRatio`. |
| `timezone` | Timezone name reported by `Intl.DateTimeFormat`. |
| `timezone_offset` | `Date.getTimezoneOffset()`, in minutes (UTC minus local time). |
| `platform` | `navigator.platform`. |
| `vendor` | `navigator.vendor`. |
| `cookie_enabled` | Browser reports cookies enabled; no cookie contents are collected. |
| `online` | Browser's reported online status. |
| `pdf_viewer_enabled` | Browser reports built-in PDF viewing support. |
| `hardware_concurrency` | Reported logical processor count. |
| `device_memory` | Reported approximate device memory in GB. |
| `max_touch_points` | Reported maximum simultaneous touch points. |
| `webdriver` | Browser's automation flag. |
| `do_not_track` | Recognized value of `navigator.doNotTrack`. |
| `global_privacy_control` | `navigator.globalPrivacyControl`. |
| `color_scheme` | Color-scheme media preference: dark, light, or no preference. |
| `reduced_motion` | Reduced-motion media preference. |
| `connection_effective_type` | Browser's estimated connection class. |
| `connection_downlink` | Browser's estimated downlink in Mbps. |
| `connection_rtt` | Browser's estimated round-trip time in milliseconds. |
| `save_data` | Browser's reduced-data preference. |
| `navigation_type` | Navigation timing type, such as navigate or reload. |

Privacy preference flags are recorded as metadata; the current script does not
use them to disable collection.

## Browser identity

The browser ID is generated by MyCount, not supplied by the browser installation.
It is saved under `mycount.visitor_id.<site>` in first-party local storage and
does not change when the visitor's IP changes. Different browsers independently
generate IDs; accidental UUID collisions are extremely unlikely.

Clearing storage, switching browser profiles/devices, or ending a private
browsing session can produce a new ID. If persistent storage is unavailable,
collection continues without an ID. This identifies browsers within a site,
not individual people across devices or websites.
